🎯 Number Guessing Game

A simple Number Guessing Game developed using Python as part of my Python Development journey.

📌 About the Project

The Number Guessing Game is a beginner-friendly Python project where the computer generates a random number and the player tries to guess it.

The program gives feedback to the player based on the entered number and continues until the correct number is guessed.

✨ Features

- 🎲 Generates a random number
- ⌨️ Takes input from the user
- 🔍 Compares the user's guess with the generated number
- 📈 Gives hints such as higher or lower
- 🏆 Displays a success message when the number is guessed
- 🔄 Allows multiple attempts

🛠️ Technologies Used

- Python
- "random" module
- "while" loop
- "if-elif-else" conditions
- User input

▶️ How to Run

1. Clone or download this repository.
2. Open the Python file.
3. Run the program using Python.
4. Enter your guessed number.
5. Follow the hints and try to find the correct number.
